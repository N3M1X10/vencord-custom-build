# vencord-custom-build
just a convenient installation script

# usage

>[!caution]
>Use this scripts on your own risks! Be sure what you are doing

- `install-custom-build.bat` - it **building** and **injecting** the vencord, with your custom plugins from `src\userplugins` dir. Paste your plugins there before using script and then you are awesome
- `clone-vencord.bat` - it clones **vencord** repo and installs `frozen-lockfile`. also updates repo to origin
- `update-customSounds.bat` - just cloning of my first choice of plugin to do this script
- `uninject-vencord.bat` - doing uninject the **vencord**
